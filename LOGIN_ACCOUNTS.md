## 🔄 Running the Seeder

### Create All Accounts:
```bash
# Run only UserSeeder
php artisan db:seed --class=UserSeeder

# Or run all seeders
php artisan db:seed

# Fresh migration + all seeders (⚠️ deletes all data!)
php artisan migrate:fresh --seed
```

### Verify Accounts Created:

## 🚀 Quick Start Commands

### Complete Setup:
```bash
# 1. Run migrations

# 2. Seed all data (including users)

# 3. Clear cache
php artisan cache:clear
php artisan view:clear

# 4. Start server
```
